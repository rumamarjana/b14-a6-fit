
1.Project Name

FITLOG – Gym & Workout Management System

2.Short Description

FITLOG is a modern gym and workout management web application that helps users plan, track, and manage their fitness activities. Users can explore workouts, create personalized workout plans, track exercise duration and calories, and save their favorite workouts.


3.Technologies Used
Next.js
React
TypeScript
Tailwind CSS
DaisyUI
React Context API
React Toastify


5 Key Features
Workout Exploration – Browse different workouts with details such as difficulty, duration, calories, and workout categories.
Personal Workout Plan – Add exercises to a personalized workout plan and manage the selected workouts.
Workout Tracking – Track total exercises, workout duration, and estimated calories burned.
Save Workouts – Save favorite workouts for quick access later.
Responsive & Modern UI – A clean, user-friendly interface that works smoothly across desktop, tablet, and mobile devices.
